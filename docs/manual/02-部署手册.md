# fast-router 部署手册

> **你是谁**：把 fast-router 装到一台机器上、配好上游、交付给使用者和运维。
> **验收标准**：§6 自检清单全绿。

---

## 1. 包结构与前置条件

```
fast-router/
├── fast-router(.exe)        # 单二进制（Go，无运行时依赖）
├── lib/                     # 评分推理库（不启用智能路由可不带）
├── fast-router.example.json # 配置模板
└── models/                  # 评分 GGUF（可后置经管理界面下载）
```

| 平台 | 前置 | 说明 |
|---|---|---|
| macOS | 无 | 启动时设 `DYLD_LIBRARY_PATH=./lib`（智能路由时） |
| Linux | glibc 环境 | `LD_LIBRARY_PATH=./lib` |
| Windows | 无 | 评分功能当前仅部分路径可用，**建议 hint-only 部署**（见已知限制） |

内存预算（启用评分时）：快评层小模型 ~0.3-1.5GB；精修层 9B ~7GB。纯代理（hint-only）<100MB。

## 2. 三档部署——按需选择

| 档 | 配置 | 效果 | 适用 |
|---|---|---|---|
| **A. 纯代理** | 不配 `model` | 多上游 + 协议转换 + 会话感知；模型靠强提示指定 | 最快上线/最小资源 |
| **B. 快评单层** | 只配 `model.fast_path`（小 GGUF） | 每个新任务 2~3s 内自动选模；续轮毫秒 | **推荐默认**：质量/成本/内存最优平衡 |
| **C. 级联双层** | `fast_path` + `path`（9B） | B 档 + 后台 38s 精修覆写 | 对首评后质量有极致要求 |

## 3. 配置（最小可用 → 全量）

```jsonc
{
  "listen": "127.0.0.1:8080",          // 上线必改：默认 :8080 监听所有网卡
  "model": {
    "fast_path": "models/router-sft.gguf",   // B/C 档必配
    "path": "",                               // C 档才配
    "lib": "lib/libfrwrapper.dylib",          // 按平台后缀
    "lib_dir": "lib"
  },
  "upstreams": {                          // 至少一个；名字自定义
    "openai":    { "base_url": "https://api.openai.com/v1", "api_key": "sk-…", "protocol": "openai" },
    "anthropic": { "base_url": "https://api.anthropic.com", "api_key": "…",   "protocol": "anthropic" }
  }
}
```

**配置规则（易错点）**：
1. `upstreams` 的键名 = registry/moa 里引用的"上游名"，自定义要前后一致
2. `base_url` 末段是版本号（`/v1`、`/v4`）时网关自动只拼方法路径（GLM 等 provider 适用）
3. `registry` 不配则用内置种子表（指向 openai/anthropic/deepseek）；自定义上游名时**必须**提供配套 registry
4. `async_score` 保持缺省 true；false 会让首请求阻塞数十秒（仅排查用）

### 3.1 可选：MoA 委员会（低置信自动升级）

```jsonc
"moa": {
  "enabled": true,
  "min_confidence": 0.5,               // 成本闸：评分置信低于此值才升级
  "references": [                       // 便宜系参考（高温=多样性）
    { "upstream": "deepseek", "model": "deepseek/deepseek-chat", "temperature": 0.6 },
    { "upstream": "openai",   "model": "openai/gpt-5-mini",       "temperature": 0.6 }
  ],
  "aggregator": { "upstream": "openai", "model": "openai/gpt-5", "temperature": 0.4 }
}
```

**性价比原则**：N 个便宜参考 + 1 个中档聚合 ≈ 一个顶级模型的价格、更高质量。工具调用请求自动跳过 MoA。

## 4. 启动

```bash
DYLD_LIBRARY_PATH=./lib ./fast-router -config fast-router.json   # macOS（Linux 用 LD_）
```

配置文件不存在时自动生成模板并提示编辑。模型文件可后置：起服务后经 `http://127.0.0.1:8080/admin` → Models 下载（modelscope 源）。

## 5. 安全加固（上线前逐条执行）

- [ ] `listen` 改为 `127.0.0.1:8080`（或仅内网网卡）——**管理界面绝不可暴露公网**
- [ ] `chmod 600 fast-router.json`（含明文 API key）
- [ ] 评估 `data/train_log.jsonl` 隐私策略（记录请求原文；敏感场景与运维确认保留策略）
- [ ] 确认 MoA `min_confidence` 不低于 0.5（防成本失控）

## 6. 上线自检清单（全绿才算交付）

```bash
# 1) 进程与监听
curl -s localhost:8080/v1/models                          # → {"data":[{"id":"fast-router"…
# 2) 上游连通（逐个）
curl -s -X POST localhost:8080/api/upstream/test -d '{"name":"openai","base_url":"…","api_key":"…","protocol":"openai"}'
# 3) 端到端（换真实模型名）
curl -s localhost:8080/v1/chat/completions -H 'Content-Type: application/json' \
  -d '{"model":"auto","messages":[{"role":"user","content":"ping"}]}'
# 4) 智能路由生效（B/C 档）：启动日志含 "fast tier ready"
# 5) MoA（若启用）：日志含 "MoA escalation enabled"
```

## 7. 升级与卸载

- **升级**：停进程 → 替换二进制（配置/数据兼容）→ 起。评分模型热换无需停（见运维手册 §热更新）
- **回滚**：恢复旧二进制/旧配置文件即可；无状态数据库
